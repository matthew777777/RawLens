⏺ You don't need a new key, so nobody has to reinstall.

  Why the key can stay. Only the password was exposed. Someone would also need
  the file Untitled.jks to sign an APK as you, and that file is only on your
  Mac. You can change both passwords and keep the same key:

  keytool -storepasswd -keystore ~/Untitled.jks
  keytool -keypasswd -alias key0 -keystore ~/Untitled.jks

  The certificate doesn't change, so updates install over the existing app as
  usual. After that, update the two RAWLENS_*_PASSWORD variables.

  What a plain key switch would do. Android only installs an update if it's
  signed by the same key as the installed app. If you just swapped to a new key,
  the update would fail with "App not installed" for everyone. Each user would
  have to uninstall, losing the app's settings and saved lens data, and then
  reinstall.

  If you ever must change keys (say the .jks itself leaks): Android 9+ supports
  key rotation through APK Signature Scheme v3. RawLens has minSdk = 30, so
  every user can take a rotated update in place. You'd create a lineage file
  that the old key signs over to the new one, and sign each later release with
  both keys:

  apksigner rotate --out lineage.bin \
    --old-signer --ks ~/Untitled.jks --ks-key-alias key0 \
    --new-signer --ks ~/new.jks --ks-key-alias key1

  That needs build changes, because Gradle's signing config alone can't apply a
  lineage, so it isn't worth doing for a password leak.

  F-Droid builds are signed with F-Droid's own key, so none of this affects
  F-Droid users.

  Also make sure you have a backup of Untitled.jks. If that file is lost,
  there's no rotation path at all, and everyone would have to reinstall.

  white balance on a Bayer sensor looks green, so the viewfinder and the JPEG

  it also opens green or broken in RAW editors. Lenses 3 and 5 most likely
  behave the same way.

  Fix. When the camera gives a NaN or missing neutral and unity or missing
  gains, RawLens now estimates the white balance from the frame's own RAW data.
  It averages about 3,000 Bayer 2×2 blocks spread across the frame, skipping
  clipped and very dark ones.
  - Viewfinder (both engines): it re-estimates twice a second and eases toward
    each new value, so the preview doesn't flicker. The first time this kicks
