# RawLens 2.2.46

## Faster LK-R processing

Full 1× merges measured approximately **23–34% faster**, or **19–25% less processing time**, in the supplied before-and-after benchmarks. Results vary with the workload; these figures are measured improvements, not a guarantee for every capture.

- Compile only the pipelines needed by the merge, with compiled pipelines cached in memory and on disk. Warm pipeline startup fell from 7–9 seconds to about 35 milliseconds: approximately **99.5–99.6% less startup time**.
- Split the deep-shadow motion test into smaller GPU passes to reduce register pressure. The test took approximately **51% less GPU time**.
- Restructure alignment loops and share reference pyramids across frames. Alignment CPU time fell approximately **38%**.
- Blend completed tiles in deterministic order while allowing workers to continue processing, with a bounded queue for completed results.
- Reuse temporal tests when motion has not changed, remove an unused gradient pass, and avoid repeated coverage calculations when no prior is active. These changes reduced measured GPU work by approximately **10%** in one benchmark.
- Fit noise alongside coarse alignment and reuse solver scratch memory.

**2× zoom showed no measurable improvement** in the supplied measurements; the after result was a single run within the previous range.

The overall percentages use the supplied 12.3 → 9.2 second and approximately 63 → 51.3 second mean results. “Faster” is calculated as before / after − 1; time saved is 1 − after / before. Individual stage gains are not additive.

## Camera selection

- Keep rear cameras before front cameras regardless of focal length.
- Group available front camera routes separately after rear routes, with unavailable routes last.

## Burst and ZSL defaults

- Increase the shared default ZSL buffer and burst / merge frame selection from 8 to 16 across capture modes. Existing saved frame-count choices remain respected; automatic frame selection and mode-specific limits still apply.

## Quick panel

- Fix quick-panel tiles in the lower rows closing the panel instead of responding to a tap on phones where the app window starts below a display cutout. The "tap outside to close" check compared screen coordinates with window coordinates; it now uses window coordinates throughout.
