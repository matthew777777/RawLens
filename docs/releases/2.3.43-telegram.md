RawLens 2.3.43 preview — Lucas–Kanade Reloaded merging is almost ready! 🚀

Mobile-focused LK-SR is up to around 3× faster in tested runs, with improved motion handling and fewer artefacts. PhotonCamera-based KernelNet denoising is now on by default: it skips low-noise scenes and ramps up when noise rises. An off switch is available.

Also: faster KB-SR with fewer tile/zipper artefacts, Basic tone mapping by default with improved highlights, autofocus recovery and expanded two-exposure RAW HDR.

Still in testing; performance varies by device and scene. Release announcement to follow.
