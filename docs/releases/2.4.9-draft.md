# RawLens 2.4.9 — Photo tone controls and RAW preview improvements

**Draft — not published.** Covers the pending photo-rendering work and the local
RAW preview optimization being pushed with it.

## Photo rendering

- More natural shadows with Sigmoid: the default shadow lift is now much subtler,
  and near-black tones stay dark instead of developing a hazy floor.
- New **Shadow lift** and **Highlight recovery** sliders in Photo output settings,
  saved per lens, with a dedicated reset. Shadow lift defaults to 20%; highlight
  recovery defaults to 0%. Set either slider to 0% to bypass its adjustment.
- Highlight recovery gently pulls bright tones down before the selected tone
  mapper, with a gradual response capped at one stop. Sigmoid retains its
  darktable-derived highlight roll-off. Automatic exposure does not undo the
  highlight recovery adjustment.
- Basic now uses **Neutral v2**, with linear midtones and a smooth transition
  through bright colors toward white. Existing saved Basic selections use the
  new response; Sigmoid remains the default mapper.
- Preview, JPEG/JXL output and scopes share the tone adjustments. JPEG metadata
  records the active controls. Original DNG data is unchanged.

## RAW preview

- More efficient GPU reads for aligned RAW buffers, with the existing path kept
  for other geometry. Resolution, sensor-level handling and the saved-image
  algorithms are preserved.
- The preview optimization has byte-exact parity evidence on tested Mali and
  host Vulkan configurations. Results are device-dependent; this is not a
  blanket frame-rate or LK-R merge-speed claim.

## Compatibility and limits

- Basic's existing Highlight shoulder slider now varies the Neutral v2 knee;
  0% retains a gentler shoulder instead of bypassing compression.
- Highlight recovery uses a pointwise adaptation of RapidRAW 1.7's tonal response,
  not its complete edge-aware local Highlights module. It cannot recover detail
  clipped in every sensor channel.
- Strong shadow lift can expose noise. Start with the new 20% default and adjust
  to taste. Existing JPEGs are not rewritten.
- Khronos Neutral attribution is included in the bundled open-source notices.

## Validation

- Full JVM suite: 2,077 tests, zero failures/errors, 10 skipped (2,067 passed).
- Connected phone: all 14 selected GPU/output, fused rendering, preview-slider
  and BGU/JNI tests passed using the isolated `.rcdcheck` application.
- Halide scalar/AOT parity: all 16 cases passed; all four Android ABI look
  libraries regenerated.
- Standalone/fused output shaders and shared GLES 2/3/3.1 helpers compiled.
- Isolated application and instrumentation APKs built successfully.
- The original supplied personal DNGs were unavailable at their previous paths;
  this revision has not been visually revalidated on those exact RAWs.

## Suggested quick check

Choose Sigmoid, leave Shadow lift at 20%, and compare it with 0%. For a bright
sky, raise Highlight recovery gradually while checking cloud detail and the
subject's brightness. Use the reset button to return both controls to defaults.
